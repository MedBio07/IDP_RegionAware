# P5.8 FusionEncoder-style Tables and Manuscript Figures

Date: 2026-08-04

## Style Reference

The FusionEncoder Bioinformatics paper reports independent-test benchmark tables using:

- per-dataset comparison rows,
- columns `Predictor`, `Sn`, `Sp`, `BACC`, `MCC`, `AUC`,
- three rank columns for `AUC`, `BACC` and `MCC`.

This project now mirrors that display style for the main benchmark comparison while keeping calibration, NR25 and hard-case evidence in separate manuscript tables.

## Scientific-Visualization Redraw

On 2026-08-05, Figure 1 was redrawn using the local `scientific-visualization` skill guidance and the architecture-figure style of FusionEncoder, IDP-EDL, IDP-LM and DisoFLAG. The updated method figure uses:

- fixed 183 mm by 156 mm physical dimensions for full-width manuscript use;
- Matplotlib Type 42 font settings for editable vector text in PDF/EPS;
- PDF, EPS, SVG and 600 dpi PNG exports;
- direct labels and dashed-line redundancy so color is not the only cue;
- an explicit JSON provenance manifest documenting source files, transformations and outputs.

The second redraw removes the flowchart-like horizontal workflow and replaces it with a scientific method architecture: a protein token track, residue feature matrices and embedding strips, a warm-start multi-kernel TCN layer, low-rank adapter internals, residue-level MoE gating and sequence-aligned probability, binary and entropy output tracks.

## Main Benchmark Display

After adding `RegionAdapterMoETCN (this work)` to the curated direct-benchmark table, the FusionEncoder-style rank table shows:

- SL329: rank 1 for AUC, BACC and MCC.
- MXD494: rank 1 for AUC, BACC and MCC, with FusionEncoder as the strongest published direct comparator.
- DISORDER723: rank 1 for AUC, rank 2 for BACC and MCC; IDP-EDL remains MCC rank 1 and FusionEncoder remains BACC rank 1.

This presentation makes the performance boundary clearer than the earlier single-row SOTA-gap table: the method has AUC-leading point estimates under full DM3000 training, but the DISORDER723 threshold-dependent metrics are not uniformly best.
