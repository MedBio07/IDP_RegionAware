# IDP-EDL local reproduction predictions

This directory publishes residue-level scores generated by the local,
audited IDP-EDL reproduction. These are predictions from the authors' public
model artifacts under the public inference protocol; they are not the
benchmark-specific predictions used to produce the paper tables.

## Public files

- `sl329_residue_predictions.tsv.gz`
- `mxd494_residue_predictions.tsv.gz`
- `disorder723_residue_predictions.tsv.gz`
- `summary.tsv` and `summary.json`: recomputed residue-level metrics
- `paper_comparison.tsv`: local minus paper-reported metric differences
- `manifest.json`: input, source-output, public-content, and gzip SHA256 values

The compressed prediction tables contain only:

```text
dataset  protein_id  position  prediction  score  max_length  truncated_residues
```

Amino-acid sequences, headers, and per-residue reference labels are
intentionally omitted to avoid redistributing the benchmark data through a
derived result file. The summaries retain only aggregate label-class and
confusion-matrix counts needed to audit the reported metrics.

## Protocol

- Runtime: FP32 inference with the public IDP-EDL component and meta weights
- Batch size: 4, matching the authors' public prediction notebook
- Maximum tokenizer length: 1024, including one EOS token
- Maximum retained protein residues: 1023
- Decision rule: positive-class score greater than 0.5
- Unknown SL329 label `2`: retained during local alignment, excluded from metrics

The authors' released SL329 sample contains 322 proteins rather than all 329.
The seven omitted entries are `DP00072`, `DP00081`, `DP00348`, `DP00519`,
`DP00557`, `DP00560`, and `DP00573`; every omitted sequence is longer than
2000 residues. No prediction is imputed for these proteins.

The local results do not reproduce every paper point estimate. In particular,
the AUC differences (local minus paper) are -0.009840 for SL329, +0.019911 for
MXD494, and -0.026184 for DISORDER723. See `paper_comparison.tsv` for all Sn,
Sp, BACC, MCC, and AUC differences.

## Attachment audit

The supplied `idp-edl.zip` is not included in this release. Its 388 arrays
have batch shapes `(4,4)` plus final partial batches, yielding exactly four
values per protein rather than one value per residue. This matches the public
script's erroneous tokenization of `[protein_name, sequence]` pairs into four
tokens. The archive contains no protein identifiers, positions, labels, or
truncation metadata and cannot be safely reshaped into residue predictions.

```text

```

All published row counts and hashes are recorded in `manifest.json`.
